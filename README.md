# cognitive-ai — landing site

Official landing page for [Cognitive AI](https://www.npmjs.com/package/@jcrandall541/cogai) — memory + discipline for AI coding agents.

Live at: https://dakotabota.github.io/cognitive-ai/

Black background, fluorescent-white lettering, zero external requests, single-file build.

- `index.html` — the site (inline CSS, optional copy-button JS)
- `404.html` — themed 404
- `robots.txt` — AI search bots allowed, training crawlers blocked
- `sitemap.xml`
- `.nojekyll` — serve raw files, skip Jekyll
- `assets/favicon.svg`

Publishes automatically from `main` via GitHub Pages.
