Why it works

  • Durable memory — a store in your own private GitHub repo; local disk is the cache and offline fallback. It refuses to sync to public remotes.
  • Enforced capture — harness hooks nudge and auto-capture after edits, so work persists without the agent remembering to remember.
  • One CLI, every agent — boot, capture, and recall the same memory from Claude, Cursor, Codex, Aider, Cline, or Windsurf.
  • Proactive — when you sit down, it tells you exactly where you left off.

How it works

  1. cogboot — loads your memory into context before the agent starts. You start warm: projects, decisions, learnings, blockers.
  2. cogcap "what changed" — one command persists the work summary. A post-edit counter reminds agents that skip it.
  3. cogscout search "task" — finds production-ready reference code on GitHub before anyone rebuilds it badly.

FAQ

What does Cognitive AI do?

Cross-session memory backed by your private GitHub repo, plus harness-enforced hooks so agents actually capture their work.

Which agents does it support?

Claude Code, Cursor, Codex, Aider, Cline, and Windsurf — one CLI and the same store for all.

What does it cost?

$9/month, license-key gated. Local dev mode: COGAI_DEV=1.

Where does my memory live?

In a private repo you own. Sync to public remotes is refused by design.

Does it work offline?

Yes — local store first, syncs when a network is available.
